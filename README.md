# 🤖 RPA Orchestrator AI

Orquestrador inteligente de tarefas e automações RPA integrado à API do Google Gemini, desenvolvido para gerenciar, monitorar e executar fluxos de trabalho automatizados.

---

### 📌 Sobre o Projeto

O **RPA Orchestrator AI** é uma solução backend desenvolvida para centralizar o controle de scripts de automação. Ele utiliza inteligência artificial para auxiliar na tomada de decisões em tempo real durante a execução de rotinas automatizadas, oferecendo controle de logs, status de tarefas e persitência de dados robusta.

### 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python
- **Framework Web:** FastAPI
- **ORM & Banco de Dados:** SQLAlchemy / SQLite
- **Inteligência Artificial:** Google Gemini API
- **Arquitetura:** REST API
